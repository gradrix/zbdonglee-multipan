First release: Nerivec's v2024.6.2 multi-PAN RCP for the SONOFF ZBDongle-E (EFR32MG21), rebuilt
with the CPC stale-completion fix (`patches/sisdk-2024.6.2-cpc-stale-completion.patch`).

Running on one dongle since 2026-11-03; it replaced the stock build, which stalled the radio link
about every 70 minutes on the same setup. 24-hour soak passed 2026-11-04: no bad frame, no stack
restart, every Zigbee probe answered (2016/2016), Thread devices attached throughout.

- SiSDK 2024.6.2, CPC protocol v5 (secondary 4.5.0), OpenThread RCP 2.5.1, BLE HCI
- UART 460800 baud, no hardware flow control
- Tested host: SiSDK 2026.6.2 packages (cpcd 4.8.0, zigbeed 9.1.1, otbr-agent 3.1.1)

Built by GitHub Actions with `./build.sh` from this tag; checksums in `SHA256SUMS`. A local build of
the same sources differs only in build stamps.

What it fixes, how it was found and how to flash it: README.md and docs/root-cause.md.
